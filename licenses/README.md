# Third-party components bundled in the app

| Component | Used for | License | File |
|---|---|---|---|
| Literata (The Literata Project Authors) | Prose typeface | SIL Open Font License 1.1 | `OFL-literata.txt` |
| Balsamiq Sans (The Balsamiq Sans Project Authors) | Comic lettering | SIL Open Font License 1.1 | `OFL-balsamiq-sans.txt` |
| Bangers (The Bangers Project Authors) | Sound effects | SIL Open Font License 1.1 | `OFL-bangers.txt` |
| Russo One (Jovanny Lemonad) | Sound effects, Cyrillic | SIL Open Font License 1.1 | `OFL-russo-one.txt` |
| Lucide icons (Lucide Contributors; parts from Feather, MIT) | Interface icons | ISC | `ISC-lucide.txt` |

The fonts are embedded in the bundled `index.html` from the `@fontsource` npm packages.
esbuild and ESLint are build tools only and are not shipped in the app.
